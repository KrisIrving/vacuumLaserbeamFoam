User selected aligned 384 rays and requested a full 1.5 mm M247 case with a first 50 microsecond run. The earlier full-ray Wang thermal proposal is not a prerequisite.

Added M247_0p6Pa_track1500um6um and RunM247TrackPilot. Process remains 350 W, 1 m/s, 0.6 Pa, 1343.15 K preheat, 86 micrometre beam. The full path takes 1500 microseconds; an explicit 1 ns laser-off ramp precedes an optional 500 microsecond cooling horizon. The first run stops at 50 microseconds.

Native blockMesh/checkMesh must pass before decomposition and CFD. Mesh topology/count and shared faces were checked locally; native quality is not certified here. This is not a moving-window implementation or a guaranteed 24-hour computation.

Thermal iteration uses existing bounded enthalpy correction with relaxation 1, standard M247 epsilon tolerance 1e-4 and phase-temperature tolerance 0.01 K, unchanged 150-corrector cap. Per-step residuals and cap hits are collected. Relaxation 1 requires native evidence; if costly or capped, use a matched restart comparison from retained 40 microsecond state. Extra inner-corrector prints are disabled without changing convergence criteria.

Runner resolves a fresh physical output directory, rebuilds laser library and solver using wmake, and uses standard OpenFOAM commands. It has no cleanup, forced kill or timeout. Build/preparation/CFD failures produce one timestamped archive with manifest and complete logs.
