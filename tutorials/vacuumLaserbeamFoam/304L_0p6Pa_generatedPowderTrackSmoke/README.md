# 304L / 0.6 Pa generated-powder moving-track smoke

This is the second target-stage integration gate.

It replaces the hand-authored 13-sphere fixture with a configuration-driven,
deterministic powder bed generated by
`tools/powderBed/generatePowderBed.py`.

## Frozen physics inherited from Wang validation v1

- nearVacuumWang 304L evaporation closure;
- chamber pressure 0.6 Pa;
- 260 W, 100 um laser;
- Fe fixed-complex-index Fresnel optics;
- epsilon=0.4 radiation;
- 48 MPI ranks.

## Engineering powder fixture

This is still an integration fixture rather than an experimental powder
specification.

Current config:
- seed: 304006;
- footprint: 280 x 280 um;
- layer-thickness limit: 60 um;
- uniform diameter support: 24-44 um;
- target geometrical solid fraction: 0.22.

For the frozen seed, the generator regression produces 56 particles with
approximately:
- actual solid fraction 0.2231;
- D10 25.15 um;
- D50 31.61 um;
- D90 39.83 um.

The exact generated `constant/powderParticles.csv` and
`constant/powderManifest.json` are the reproducibility record.

## Moving laser smoke path

The laser continues to use the engineering smoke path:
- x=-40 um at 0;
- x=0 at 20 us;
- nominal scan speed 2 m/s.

These values are not yet experimental target inputs.
